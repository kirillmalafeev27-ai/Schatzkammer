# Как устроены задания

> **Генерация теперь как в «Шахте».** Задания у модели запрашивает [`quiz-generation.cjs`](../quiz-generation.cjs) —
> тот же модуль, что в «Шахте» и See Escape, копия байт в байт: короткий запрос с правилом темы
> (`TOPIC_RULES`) и ответ в тексте «AUFGABEN / LOESUNGEN». Запрос по системе Druckmaschine,
> описанной ниже, весил около 16 000 знаков и вместе с ответом (14 заданий с переводом и разбором)
> стоил почти впятеро дороже вызова «Шахты», поэтому модель его больше не получает (DECISIONS.md, 51).
>
> Система Druckmaschine осталась для **встроенного резерва**: резервные задания написаны в её
> девяти форматах, и тест прогоняет каждое через проверку `exercise-validation.ts`. Форматы задают и
> русскую инструкцию над сгенерированным заданием: игра определяет формат по виду задания
> (один пропуск — `luecke`, два — `mehrfachluecke`, «→ Perfekt» — `umformung`, «(1 Fehler)» —
> `fehlerkorrektur`, части через `/` — `wortstellung`, иначе — `satzvarianten`). Такую разметку
> генератор пишет для тем из `TOPIC_TASK_MIX` — пока это Perfekt, где одна Lücke оставляла только
> выбор haben/sein.

Ниже — устройство системы Druckmaschine (ветка `happy-shannon`), по которой написан и проверяется резерв.

| Модуль                                                                                  | За что отвечает                                                                                                            |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [`src/learning/task-formats.ts`](../src/learning/task-formats.ts)                       | каталог из 9 форматов заданий с разобранными примерами, инструкции и подсказки панели                                      |
| [`server/exercises/grammar-rules.ts`](../server/exercises/grammar-rules.ts)             | 60 грамматических тем: правило, дизайн задания, форматы, дистракторы, запреты                                              |
| [`server/exercises/quality-rules.ts`](../server/exercises/quality-rules.ts)             | общие правила: субстанция вариантов, качество дистракторов, список брака, тест закрытия, самопроверка, смешивание форматов |
| [`server/exercises/exercise-validation.ts`](../server/exercises/exercise-validation.ts) | проверка задания — сейчас резервного                                                                                       |

## Главная проблема, которую решает система

Типовой плохой вопрос:

```
Er versucht, den Bahnhof ___ finden.
A) zu     B) –     C) zum     D) um zu
```

Это не упражнение. Тот, кто знает конструкцию, узнаёт ответ мгновенно; тот, кто не знает, —
гадает из четырёх, и три варианта отпадают сами, потому что это не немецкий язык. Проверяется
не владение `Infinitiv mit zu`, а узнавание частицы.

Та же тема правильно:

```
Выбери грамматически правильный вариант.
Sein Zug fährt um sechs. (vorhaben – früh aufstehen)

A) Er hat vor, morgen früh aufzustehen.      ← верно
B) Er hat vor, morgen früh zu aufstehen.
C) Er hat vor, morgen früh aufstehen zu.
D) Er hat vor, morgen früh aufstehen.
```

Варианты — целые предложения из одного и того же материала, различаются только положением
`zu`. Угадать по длине, по «единственному осмысленному варианту» или по побочной ошибке нельзя.

## Правило субстанции

Главное правило генератора: **вариант ответа содержит всю целевую структуру, а не один
элемент из неё.**

| Тема                                                          | Что должно быть в варианте                                            | Что запрещено                      |
| ------------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------- |
| Infinitiv mit zu                                              | вся инфинитивная группа или предложение целиком                       | `zu / – / zum / um zu`             |
| Падежи, артикли, склонение прилагательных, предлоги с падежом | вся именная группа: `ihrer neuen Kollegin`, `mit dem Bus`             | `dem / den / der / des`            |
| Perfekt, Sein vs. haben, Passiv, Futur, Werden, модальные     | весь глагольный комплекс, лучше двойным пропуском: `ist – aufgewacht` | одно причастие, голое `ist / hat`  |
| Порядок слов, придаточные, рамка, damit-Sätze                 | всегда целые предложения                                              | обрывки                            |
| Relativsätze, Relativpronomen                                 | местоимение с окружением: `mit denen`, `deren Sohn`                   | `der / den / dem / dessen`         |
| Komparativ, Superlativ, даты                                  | вся группа: `älter als`, `am schnellsten`, `am dritten Mai`           | голое прилагательное или окончание |

Единственное исключение — когда целевое явление действительно одно слово: выбор союза
(`als / wenn / wann`), значение модального глагола, предлог при управлении, местоимение,
вопросительное слово. Тогда решение несёт контекст — мини-диалог или однозначные слова-сигналы,
— и материал задания не короче восьми слов. Код это проверяет.

## Девять форматов

Вместо одного «вставь пропуск» — девять форматов. Для каждой темы в
`grammar-rules.ts` перечислено, какие из них подходят; в запрос попадают только они, с
разобранными примерами. Инструкцию над заданием ставит игра по формату, модель её не пишет.

### 1. `satzvarianten` — выбор целого предложения

_Инструкция:_ «Выбери грамматически правильный вариант.»
_Материал:_ ситуация в одном предложении и в скобках опорные слова, из которых строится ответ.
_Варианты:_ четыре полных предложения из одного и того же материала; различаются только целевым
явлением (форма, позиция, рамка).
_Темы:_ порядок слов, рамка, Infinitiv mit zu, придаточные, отделяемые глаголы, Passiv, Konjunktiv.

Пример — выше, в разделе о главной проблеме. В режиме «Воспроизведение» этот формат идёт с
вариантами: по опорным словам можно построить слишком много верных предложений.

### 2. `umformung` — преобразование

_Инструкция:_ «Преобразуй предложение по заданию.»
_Материал:_ верное исходное предложение и **точное** название целевой формы.
_Варианты:_ четыре полных предложения в целевой форме.

```
Ins Passiv Präsens umformen: "Der Mechaniker repariert das Auto."

A) Das Auto wird vom Mechaniker repariert.      ← верно
B) Das Auto wird von dem Mechaniker reparieren.
C) Das Auto ist vom Mechaniker repariert.
D) Das Auto wurde vom Mechaniker repariert.
```

C (Zustandspassiv) и D (Präteritum) сами по себе грамматичны — их исключает инструкция
«Passiv Präsens». Это разрешено и сильно именно потому, что целевая форма названа точно.

### 3. `verbindung` — соединение предложений

_Инструкция:_ «Соедини два предложения в одно.»
_Материал:_ два верных предложения и нужное средство связи (союз, относительное придаточное,
парный союз).
_Варианты:_ четыре полных сложных предложения.

```
Verbinde mit einem Relativsatz: "Der Turm ist sehr alt." + "Man kann den Turm vom Bahnhof aus sehen."

A) Der Turm, den man vom Bahnhof aus sehen kann, ist sehr alt.   ← верно
B) Der Turm, der man vom Bahnhof aus sehen kann, ist sehr alt.
C) Der Turm, dem man vom Bahnhof aus sehen kann, ist sehr alt.
D) Der Turm, den man kann vom Bahnhof aus sehen, ist sehr alt.
```

Падеж надо вывести из роли местоимения в придаточном **и** удержать место глагола: три разные
настоящие ошибки.

### 4. `fehlerkorrektur` — исправление ошибки

_Инструкция:_ «В предложении одна ошибка. Выбери исправленный вариант.»
_Материал:_ предложение ровно с одной ошибкой по теме.
_Варианты:_ одно исправленное, одно повторяет ошибку без изменений, два «исправляют» неверно.

```
Ich bleibe heute zu Hause, weil ich habe Fieber.

A) Ich bleibe heute zu Hause, weil ich Fieber habe.   ← верно
B) Ich bleibe heute zu Hause, weil habe ich Fieber.
C) Ich bleibe heute zu Hause, weil ich habe Fieber.
D) Ich bleibe heute zu Hause, denn ich Fieber habe.
```

C — неизменённое предложение с ошибкой: сильный дистрактор для того, кто ошибку не видит.

### 5. `dialog` — мини-диалог

_Инструкция:_ «Прочитай ситуацию и выбери подходящий вариант.»
_Материал:_ две-три реплики или короткая ситуация; пропуск в ответе. Решает **только** контекст.
_Варианты:_ четыре формы, грамматически возможные все; к ситуации подходит одна.

```
— Muss ich das Formular heute abgeben? — Nein, du ___ es nicht heute abgeben. Du hast noch bis Freitag Zeit.

A) musst   ← верно      B) darfst      C) sollst      D) kannst
```

Однословные варианты здесь законны: целевое явление — значение модального глагола. «Есть время
до пятницы» = нет необходимости, а не запрет; `darfst` — классическая ошибка. Перевод задания
оставляет «…» на месте пропуска, иначе он сам выдал бы ответ.

### 6. `mehrfachluecke` — двойной пропуск

_Инструкция:_ «Заполни оба пропуска.»
_Материал:_ предложение с двумя (реже тремя) пронумерованными пропусками, связанными грамматикой.
_Варианты:_ каждый заполняет **все** пропуски, через « – ». Лучше всего — матрица 2×2.

```
Gestern (1) ___ meine Schwester mit dem Zug nach Hamburg (2) ___ .

A) ist – gefahren   ← верно
B) hat – gefahren
C) ist – gefahrt
D) hat – gefahrt
```

Ось 1 — выбор вспомогательного глагола, ось 2 — образование причастия. Угадывание даёт 25 %,
половинное знание — 50 %, и то и другое видно в статистике.

### 7. `wortstellung` — сборка предложения

_Инструкция:_ «Составь предложение из данных частей.»
_Материал:_ члены предложения через « / » в **случайном** порядке — никогда не в правильном.
_Варианты:_ четыре полных предложения ровно из этих частей.

```
ins Kino / heute Abend / mit meiner Schwester / ich / gehe

A) Heute Abend gehe ich mit meiner Schwester ins Kino.   ← верно
B) Heute Abend ich gehe mit meiner Schwester ins Kino.
C) Heute Abend ich mit meiner Schwester ins Kino gehe.
D) Gehe ich heute Abend mit meiner Schwester ins Kino.
```

«Ich gehe heute Abend mit meiner Schwester ins Kino.» тоже верно, поэтому **не** может стоять
среди неверных вариантов: все дистракторы нарушают место глагола.

### 8. `bedeutung` — минимальная пара

_Инструкция:_ «Выбери вариант, который подходит по смыслу.»
_Материал:_ ситуация, которая однозначно требует одну из двух похожих структур.
_Варианты:_ несколько сами по себе грамматичны; ситуации соответствует один.

```
— Wo ist meine Brille? — Du hast sie doch selbst ___ gelegt!

A) auf den Tisch   ← верно     B) auf dem Tisch     C) auf der Tisch     D) auf die Tische
```

`legen` задаёт направление и значит Akkusativ; B — вариант «где?», самая частая ошибка.

### 9. `luecke` — пропуск со всей структурой

_Инструкция:_ «Выбери правильный вариант.»
_Материал:_ предложение ровно с одним пропуском и достаточным контекстом.
_Варианты:_ каждый содержит **всю** целевую структуру, а не служебное слово из неё.

```
Zum Geburtstag hat Anna ___ einen großen Blumenstrauß geschenkt.

A) ihrer neuen Kollegin   ← верно
B) ihre neue Kollegin
C) ihrer neue Kollegin
D) ihren neuen Kollegen
```

Пропуск закрывает всю именную группу (притяжательный артикль + прилагательное +
существительное) — проверяется решение о падеже, а не узнавание одного слова.

## Смешивание форматов

В пакете из 10 заданий — минимум 4 разных формата (но не больше, чем разрешено теме), не
больше 4 заданий одного формата и минимум 2 задания из сложных форматов (`umformung`,
`verbindung`, `fehlerkorrektur`, `bedeutung`), если тема их допускает. Подлежащие, глаголы,
лица, числа и длина предложений тоже меняются от задания к заданию.

## Дистракторы

1. Каждый дистрактор — **настоящая** ошибка учащегося этого уровня, а не выдуманная словесная каша.
2. Минимум два из трёх привлекательны: они были бы верны в соседнем контексте (другой падеж,
   другое время, другой союз, другой род).
3. Каждый дистрактор ошибается **ровно в одном**, и это одно относится к теме. Вариант с
   побочной ошибкой в личном окончании или с опечаткой бесполезен: его отбрасывают, не понимая
   темы.
4. Все четыре варианта похожей длины и устроены одинаково.
5. Все четыре — из одного лексического материала.
6. Дистрактор может быть грамматичным сам по себе, если его однозначно исключает инструкция.
7. Позиция правильного ответа распределяется равномерно (игра ещё и перемешивает варианты).

## Брак, который запрещён

Задание на служебное слово; задание на согласование (ответ следует из подлежащего: wir → uns);
мусорный вариант; два верных варианта; ловушка не по теме; предложение без контекста;
однообразная серия; оборванное предложение; выданное решение (верный вариант — единственный
немецкий). Перед выдачей модель прогоняет **тест закрытия**: может ли ученик, не знающий
темы, но в остальном знающий немецкий, решить задание через согласование, лексику, длину
вариантов или отсев бессмыслицы? Если да — задание переписывается.

## Уровни

Запрос Druckmaschine разворачивал «уровень A2» в конкретные ограничения: длина предложения,
разрешённые и запрещённые структуры, пласт лексики, замечание о подходящих форматах. Сборщик
запроса (`exercise-prompt.ts`) удалён вместе с генерацией по этой системе; генератор «Шахты»
пишет в запрос «Verwende keine Grammatik und keinen Wortschatz ueber A2».

## Что проверяет код, а не запрос

`exercise-validation.ts` отбраковывает то, что модель всё равно иногда присылает:

- не ровно 4 варианта, пустые или повторяющиеся варианты, пропуск `___` внутри варианта;
- оборванное предложение (заканчивается на `...`);
- расхождение между номером правильного ответа и его текстом — модель обязана продублировать
  ответ дословно;
- формат не указан, не существует или не разрешён теме;
- число пропусков не соответствует формату; у двойного пропуска вариант не заполняет все пропуски;
- сборка предложения: части уже стоят в правильном порядке или ответ не тратит их все;
- исправление ошибки: «исправленный» вариант совпадает с предложением с ошибкой;
- **нарушение правила субстанции**: все четыре варианта короче минимума для темы;
- однословные варианты при материале короче восьми слов; вариант без немецкого слова («–»);
- форматам предложений — не предложения;
- варианты, отличающиеся по длине больше чем в 5 раз;
- нет русского перевода или разбора; мир игры или ИИ в тексте;
- дубли внутри пакета и повтор уже выданных заданий;
- перекос по форматам: лишние задания одного формата уходят в конец очереди.

`describeRejections` собирает причины отбраковки в одну строку:

```
[Infinitiv mit zu B1] 8/12 Aufgaben übernommen; aussortiert: Füllwort-Optionen: Thema verlangt mindestens 3 Wörter je Option ×2; doppelte Optionen
```

Сгенерированные задания проверяет сам `quiz-generation.cjs`: ровно четыре разных варианта A–D,
у задания есть ключ в LOESUNGEN, и текст ключа совпадает с текстом варианта. Клиент отбрасывает
повторы уже показанного.

## Что видит игрок

Перевод и разбор есть только у резервных заданий: генератор «Шахты» их не пишет, и панель тогда
просто их не показывает.

- **Инструкция** — по формату (см. выше).
- **Материал** — немецкий; пропуски показаны чертой.
- **Перевод** — русский перевод решённого задания; у мини-диалога и минимальной пары — перевод
  ситуации с «…» на месте пропуска.
- **Подсказка** над вариантами — своя у каждого формата и режима.
- **Разбор** после ответа — какое правило решает задание и в чём ошибка сильнейшего дистрактора.
- В режиме «Воспроизведение» ответ вводится текстом: целое предложение для форматов
  предложений, слова по порядку для двойного пропуска. «Выбор целого предложения» идёт с
  вариантами.

## Резерв

Когда генерация не настроена или пакет не успел прийти, играет встроенный резерв
(`src/learning/questions.ts`): 33 задания A1–B2 в восьми форматах. Тест прогоняет каждое через
проверку `exercise-validation.ts`.

## Как добавить тему

1. Добавить название в `GRAMMAR_TOPICS` и в одну из групп `GRAMMAR_TOPIC_GROUPS`
   (`src/learning/settings.ts`).
2. Для запроса к модели — при желании правило в `TOPIC_RULES` генератора; править его нужно в
   See Escape и копировать байт в байт в «Шахту» и сюда.
3. Для резерва — запись в `GRAMMAR_RULES` (`server/exercises/grammar-rules.ts`) с полями `rule`,
   `design`, `formats`, `traps`, `avoid` — или синоним в `TOPIC_ALIASES`, если запись уже есть.
4. Если целевая структура больше одного слова — внести тему в `PHRASE_TOPICS` или
   `SENTENCE_TOPICS` (`server/exercises/exercise-validation.ts`).
5. `npm test` — тесты проверяют, что у каждой темы меню есть правила, что все указанные форматы
   существуют и что пример каждого формата проходит проверку.

Названия в ASCII-транслитерации (`Praeteritum`, `Relativsaetze`) тоже находятся: `resolveTopic`
нормализует умлауты и знает список синонимов.
