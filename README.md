# Сокровищница · Die Schatzkammer

Игра для тренировки немецкого. Каждый верный ответ — шаг искателя сокровищ по залу. Золото тяжелеет, дверь опускается с первой секунды: успел выйти — добыча твоя, не успел — ноль.

Phaser 4 + TypeScript, весь арт рисуется кодом в стиле комикса, свет — собственный шейдер. Вопросы задаёт обучающий движок Conveyor: 49 лексических и 52 грамматические темы от A1 до B2, режимы узнавания, свободного воспроизведения и аудирования, генерация пакетов на сервере и встроенный резерв.

## Запуск

```bash
npm install
cp .env.example .env.local   # задайте AITUNNEL_API_KEY — без него игра идёт на встроенном резерве
npm run dev                  # http://localhost:5173, API движка подключено к тому же серверу
```

Рабочий режим — один Node-процесс отдаёт и игру, и API:

```bash
npm run build      # клиент в dist/, сервер в dist-server/
npm start          # http://0.0.0.0:3000 (PORT, HOST — переменные окружения)
```

Ключи читаются из окружения, `.env.local` и `.env` и в браузер не попадают. Все переменные — в [`.env.example`](.env.example).

Параметры адреса:

| Параметр    | Что делает                                                                 |
| ----------- | -------------------------------------------------------------------------- |
| `?level=3`  | сразу открыть зал 3 (`7` — бесконечный зал)                                |
| `?debug`    | панель отладки (в режиме разработки она открывается клавишей <kbd>`</kbd>) |
| `?art=grey` | серый прототип вместо комиксного арта                                      |
| `?test`     | выключить автопереключение качества по FPS (для автотестов)                |

Управление: нажать на плиту — цель шага; <kbd>1</kbd>–<kbd>4</kbd> — ответ; <kbd>Enter</kbd> — отправить свободный ответ; стрелки — шаг в сторону; <kbd>H</kbd> — к выходу; <kbd>Пробел</kbd> — отменить цель; <kbd>Q</kbd> / <kbd>E</kbd> — выбросить монету / камень; <kbd>P</kbd> или <kbd>Esc</kbd> — пауза (из поля ответа — только <kbd>Esc</kbd>).

## Обучающий движок

Правила перенесены из Conveyor без изменений по содержанию: те же темы, форматы, свод правил, запросы к модели, проверки её ответа и правила пула.

**Меню.** «Играть» открывает выбор зала, а над залами — блок «Немецкий», как стартовое окно Conveyor: уровень (A1–B2), режим, лексика (49 тем в шести группах) и грамматика (52 темы в восьми группах, последняя — «Лексика» с Wortfelder). Рядом — состояние пула: «AI-пул активен», если генерация настроена на сервере, и «умный резерв активен», если нет. Выбор сохраняется (`treasury:learning`).

**Режимы.**

- Узнавание — четыре варианта, клавиши <kbd>1</kbd>–<kbd>4</kbd>.
- Воспроизведение — ответ вводится текстом. Сначала строгое сравнение (регистр, пунктуация и пары ä/ae, ö/oe, ü/ue не ошибки), затем, если не совпало, смысловая проверка моделью на сервере: равнозначная формулировка принимается, другой смысл — нет.
- Аудирование — немецкая фраза только звучит (ElevenLabs при ключе, иначе голос браузера), варианты — русские переводы, «▶ Повторить» проигрывает её снова. Своя очередь `audio | уровень | лексика`: к грамматике не привязано.

**Форматы** ([`src/learning/formats.ts`](src/learning/formats.ts)):

- `gap` — фраза с ровно одним пропуском `___`; варианты отличаются только проверяемым признаком.
- `word-order` — части предложения через `/`; ответ обязан потратить все части и ничего не добавить.
- `word-field` — Wortfelder: пропуск на месте стёртого слова (`sagen`, `gehen`, `gut` …), варианты — синонимы одного поля из каталога, на панели всё поле из пяти слов, перевод держит нейтральное слово, чтобы не выдать нюанс.
- `audio` — см. выше; после ответа фраза показывается в строке разбора.

`TOPIC_RULES` — построчный свод правил по грамматическим темам, уходит в каждый запрос вместе с требованиями к качеству.

**Панель вопроса** показывает инструкцию формата, уровень и тему, задание, перевод, поле слова, подсказку и строку разбора. Разбор ответа остаётся под следующим вопросом приглушённым, пока игрок не ответит снова. На телефоне панель ужимается сама: сначала шрифт и отступы, на 360 × 640 — инструкция и банк слова в строку, а разбор всплывает поверх задания на время ответа.

**Пул** ([`src/learning/pool.ts`](src/learning/pool.ts)) — правила Conveyor:

- своя очередь на `уровень | лексика | грамматика`; узнавание и воспроизведение делят одну;
- пакет из 8 заданий запрашивается, когда в очереди меньше 3; пустой ответ — повтор через 12 с;
- последние 80 формулировок помнятся, 60 из них уходят серверу в `exclude`;
- вопрос с ошибкой возвращается в хвост очереди, но не показывается два раза подряд;
- пока очереди нет, без ожидания берётся встроенный разноуровневый резерв — сначала задания своей темы;
- пул начинает пополняться на экране выбора зала, а вопрос выбирается в момент показа, так что первые вопросы раунда уже из пакета.

**Сервер** ([`server/`](server)) — те же маршруты, что в Conveyor:

| Маршрут                        | Что делает                                                      |
| ------------------------------ | --------------------------------------------------------------- |
| `POST /api/questions/generate` | пакет заданий через AITunnel или любой OpenAI-совместимый API   |
| `POST /api/questions/evaluate` | проверка свободного ответа                                      |
| `GET /api/questions/status`    | готовность генерации и озвучки — без ключа, провайдера и модели |
| `POST /api/tts`                | mp3 по немецкой фразе, с кэшем в памяти                         |
| `GET /healthz`                 | проверка живости                                                |

Ответ модели проверяется построчно: ровно один пропуск, кириллица только в инструкции и переводе, `correctAnswer` совпадает с вариантом, части порядка слов складываются в ответ, синонимы сверяются с каталогом и уровнем, мир игры не протекает в задания. Неполный пакет не отдаётся, готовый кэшируется на 30 минут, после неудачи — пауза 15 с. Частота ограничена по клиенту и в целом. Если сервер сообщил, что генерация не настроена, клиент не шлёт запросов и играет резервом.

## Команды

```bash
npm test           # правила, поиск пути, генератор, планировщик, темп, банк вопросов, обучающий движок и API
npm run lint
npm run build      # проверка типов + сборка в dist/
npm run sim        # боты проходят все залы, отчёт по стратегиям
npm run sim -- --level 3 --runs 2000 --tmed 5000 --p 0.8
npm run sim -- --level 5 --override '{"obstacles":6}'   # проба варианта уровня
npm run shots      # скриншоты Playwright (нужен запущенный npm run dev)
npm run shots -- --sizes 390x844,1280x720 --scenario round --out shots
```

## Встраивание

Без `questions` игра берёт встроенный обучающий движок (как на автономной странице). Свой источник подключается так:

```ts
import { mountTreasury, type QuestionProvider } from './src/embed';

const questions: QuestionProvider = {
  async next() {
    return {
      id: 'q1',
      prompt: 'Ich ___ müde.',
      promptLang: 'de',
      options: ['bin', 'bist', 'ist'],
      optionsLang: 'de',
      correctIndex: 0,
    };
  },
  report({ id, correct, timeMs }) {
    // ответ игрока — для статистики или интервальных повторений
  },
};

const game = mountTreasury(document.getElementById('host')!, {
  questions,
  level: 1, // необязательно
  storage: { get: (k) => localStorage.getItem(k), set: (k, v) => localStorage.setItem(k, v) }, // необязательно
  onFinish: ({ level, escaped, score, stars }) => {}, // необязательно
});

game.destroy();
```

Игра не знает, откуда берутся вопросы: годится любой источник с `next()` и `report()`. Необязательные поля вопроса включают форматы движка: `instruction`, `meta`, `translation`, `rule`, `audioText`, `wordField`, `hint` и `recall` (свободный ответ, проверка — `evaluate()` источника). Простой пример источника — `LocalBankProvider` с банком `src/questions/bank.de.json` (60 проверенных вопросов).

## Устройство

```
src/core/       правила: чистый детерминированный TypeScript без Phaser — редуктор, генератор залов, планировщик, оценка риска
src/config/     все числа (balance.ts, levels.ts) и все цвета (palette.ts)
src/art/        процедурный комикс: обводка, растр, штриховка; рецепты пола, стен, героя, добычи, двери
src/render/     свет ComicLight, виды героя, предметов, двери, песка, эффекты
src/scenes/     BootScene (запекание атласов) и GameScene
src/ui/         DOM-интерфейс: панель вопроса, мешок, экраны меню, залов, итогов, настроек
src/audio/      синтезатор на WebAudio: эффекты, пещерная реверберация, эмбиент
src/questions/  интерфейс вопросов и локальный банк
src/learning/   обучающий движок Conveyor: темы, форматы, резерв, пул, проверка ответа, озвучка
server/         API движка: генерация, проверка ответа, озвучка; Vite-плагин и рабочий сервер
tools/          sim.ts (симуляция ботами), shots.ts (скриншоты)
```

Отклонения от плана, их причины и отчёт симуляции баланса — в [DECISIONS.md](DECISIONS.md).
